📊 Risk Evaluation
Risk Evaluation is a web application for employee risk assessment, designed to analyze, visualize, and score employee risk factors. It uses a modern tech stack for a smooth, responsive experience and includes clean animations and a reusable codebase.

🔍 Overview
This project provides a modern interface for evaluating and visualizing employee risk levels.
It leverages GSAP for smooth animations, Vite + React for a fast frontend, and Express.js for backend logic and data handling.

⚙️ Tech Stack
⚛️ React.js (Frontend)

⚡ Vite (Build Tool)

🎨 Tailwind CSS (Styling)

🎥 GSAP (Animations)

🟢 Node.js + Express.js (Backend)

📊 Chart.js (Visualizations)

🗃️ MongoDB (or any DB, if used — update accordingly)

✨ Features
✅ User-friendly risk assessment form
✅ Dynamic charts and risk scores
✅ Smooth animations with GSAP
✅ Responsive & clean UI/UX
✅ Modular & reusable components
✅ Basic backend for handling evaluation logic
